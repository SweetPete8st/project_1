How to record a good session
  1. Tap Start, allow Motion & Location.
  2. Turn ON Guided Access first (Settings → Accessibility → Guided Access), triple-click the side button after opening this page, and disable touch — pocket fabric can't stop the recording then. Screen stays on.
  3. Phone goes in a front pocket, screen facing your leg.
  4. Skate: do ~10 ollies with a few seconds between, some pushing, some cruising, one hard stop. Say what you did out loud if you're filming.
  5. Triple-click to exit Guided Access, tap Stop, then Share → save/AirDrop the file and upload it in the Claude chat.
